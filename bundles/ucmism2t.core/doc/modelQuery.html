module ucmism2t::queries::modelQuery

Module contains queries with a UML model as receiver. This includes queries for retrieving model metadata (acronym, title, version, URI, language), navigating the model structure (main package, all classes, all data types, all packages), and property file access. Note: The main package is the top-level package of the model as specified by the property MAIN_PACKAGE_NAME. All generation targets operate on the main package rather than the model root directly. Note: Model metadata is resolved in order of priority: (1) property file value, (2) ModelIdentification data type in the model, (3) built-in fallback value. This allows property file values to override model metadata without modifying the model. Related modules: - packageQuery: queries with a UML package as receiver, since Model is a subtype of Package in UML - classQuery: queries with a UML class as receiver - dataTypeQuery: queries with a UML data type as receiver
Metamodels http://www.eclipse.org/uml2/5.0.0/UML, http://www.eclipse.org/uml2/5.0.0/Types, http://www.eclipse.org/uml2/5.0.0/UML/Profile/Standard
