template public pu_itemDefinition

[template public pu_itemDefinition(item : uml::Classifier, attributes : String, multiplicity : Boolean, packageName : String, color : String, fontColor : String)]
Creates a UML diagram for items in PlantUML code. Items are classes or data types. Different groups of items have certain colors. A convenient context diagram of an item can be displayed with mainItemsLinks=all, mainItemsAttributes=all, mainItemsInheritance=true, associationToSuperclasses=false, packageName=other, designPatterns=true, otherSpecifications=true.
