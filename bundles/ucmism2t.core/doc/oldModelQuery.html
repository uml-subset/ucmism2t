module ucmism2t::templates::query::oldModelQuery

Module contains all model queries. Queries with prefix "e_" are migrated from Acceleo 3.7. Queries with prefix "u_" are written for Acceleo 4.

public OrderedSet(uml::Class) OKu_incomingAssociatedClasses(aClass) Returns all classes that are sources of incoming binary directed associations pointing to the specified class. Alphabetically sorted, deduplicated set of classes that have an outgoing association pointing to this class. Uses eInverse() to find all uml::Property elements whose type reference points to aClass, then resolves the source class via getOtherEnd().type on the association end that is owned by the source class (ownedAttribute). Self-associations are excluded from the result. --- AQL operations used: eInverse(uml::Property) - Finds all Property instances whose type EReference cross-references aClass; requires all resources to be loaded in the same resource set. ->select(p1 | cond) - Keeps only association ends owned by a class (not by the association itself). p1.association - EReference: the owning Association element; null if not an association end. eContainingFeature() - Returns the EReference via which p is contained; .name = 'ownedAttribute' confirms the property is source-class-owned, not owned by the Association (ownedEnd). ->collect(p2 | expr) - Transforms each qualifying property. p2.getOtherEnd() - Java method on uml::Property: returns the opposite end of a binary association. Not an EStructuralFeature; must be called with explicit parentheses in AQL. .type - EReference: the classifier typing the other end (i.e., the source class); typed as uml::Type, narrowed by filter below. ->filter(uml::Class) - Retains only uml::Class instances; also drops null values safely. ->reject(c1 | c1 = aClass) - Excludes self-associations. ->asOrderedSet() - Deduplicates the result collection. ->sortedBy(c2 | c2.name) - Sorts alphabetically by class name.
public String u_typeQualifiedName(aType) Returns the qualified name of a UML type. For resolved types, returns the name property directly. For unresolved UML primitive type proxies (e.g. Boolean, Integer, String, Real from UMLPrimitiveTypes.xmi), the name is extracted from the toString() representation since the name property returns empty on unresolved proxies. Note: this workaround is not necessary if UMLResourcesUtil.init( resourceSet) is registered in the generator launcher, in which case all primitive type proxies resolve correctly and name is always accessible. The workaround degrades gracefully when registration is present.

query public OKu_incomingAssociatedClasses

[query public OKu_incomingAssociatedClasses(aClass : uml::Class) : OrderedSet(uml::Class) = ...]
Returns all classes that are sources of incoming binary directed associations pointing to the specified class. Alphabetically sorted, deduplicated set of classes that have an outgoing association pointing to this class. Uses eInverse() to find all uml::Property elements whose type reference points to aClass, then resolves the source class via getOtherEnd().type on the association end that is owned by the source class (ownedAttribute). Self-associations are excluded from the result. --- AQL operations used: eInverse(uml::Property) - Finds all Property instances whose type EReference cross-references aClass; requires all resources to be loaded in the same resource set. ->select(p1 | cond) - Keeps only association ends owned by a class (not by the association itself). p1.association - EReference: the owning Association element; null if not an association end. eContainingFeature() - Returns the EReference via which p is contained; .name = 'ownedAttribute' confirms the property is source-class-owned, not owned by the Association (ownedEnd). ->collect(p2 | expr) - Transforms each qualifying property. p2.getOtherEnd() - Java method on uml::Property: returns the opposite end of a binary association. Not an EStructuralFeature; must be called with explicit parentheses in AQL. .type - EReference: the classifier typing the other end (i.e., the source class); typed as uml::Type, narrowed by filter below. ->filter(uml::Class) - Retains only uml::Class instances; also drops null values safely. ->reject(c1 | c1 = aClass) - Excludes self-associations. ->asOrderedSet() - Deduplicates the result collection. ->sortedBy(c2 | c2.name) - Sorts alphabetically by class name.

Parameters

aClass : uml::Class
aClass - The target class whose incoming association sources are to be retrieved.

Returns

OrderedSet(uml::Class)

query public u_typeQualifiedName

[query public u_typeQualifiedName(aType : uml::Type) : String = ...]
Returns the qualified name of a UML type. For resolved types, returns the name property directly. For unresolved UML primitive type proxies (e.g. Boolean, Integer, String, Real from UMLPrimitiveTypes.xmi), the name is extracted from the toString() representation since the name property returns empty on unresolved proxies. Note: this workaround is not necessary if UMLResourcesUtil.init( resourceSet) is registered in the generator launcher, in which case all primitive type proxies resolve correctly and name is always accessible. The workaround degrades gracefully when registration is present.

aType : uml::Type
aType - A UML type whose simple name is to be returned,
