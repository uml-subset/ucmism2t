module ucmism2t::queries::dataTypeQuery

Module contains queries with a UML data type as receiver. This includes queries for navigating the data type hierarchy (supertypes, subtypes), finding properties that use a data type, and data type classification. Note: Queries applicable to both classes and data types are in classifierQuery, since both are subtypes of Classifier. Related modules: - classQuery: queries with a UML class as receiver - classifierQuery: queries with a UML classifier as receiver, applicable to both classes and data types
Metamodels http://www.eclipse.org/uml2/5.0.0/UML, http://www.eclipse.org/uml2/5.0.0/Types, http://www.eclipse.org/uml2/5.0.0/UML/Profile/Standard
