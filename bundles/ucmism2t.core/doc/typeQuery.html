module ucmism2t::queries::typeQuery

Module contains queries with a UML type as receiver. This includes queries for retrieving the type name of both regular types and UML primitive types, and for classifying types as primitive or non-primitive. Note: UML primitive types (String, Integer, Boolean, Real) require special handling since their name property is not directly accessible when loaded as proxies. The queries in this module provide a uniform interface for all type name retrieval regardless of whether the type is a primitive or a regular classifier. Related modules: - classifierQuery: queries with a UML classifier as receiver, since Classifier is a subtype of Type - classQuery: queries with a UML class as receiver - dataTypeQuery: queries with a UML data type as receiver
Metamodels http://www.eclipse.org/uml2/5.0.0/UML, http://www.eclipse.org/uml2/5.0.0/Types, http://www.eclipse.org/uml2/5.0.0/UML/Profile/Standard

public String u_typeName(aType) Returns the simple name of a UML type. For resolved types, returns the name property directly. For unresolved UML primitive type proxies (e.g. Boolean, Integer, String, Real from UMLPrimitiveTypes.xmi), the name is extracted from the toString() representation since the name property returns empty on unresolved proxies. Note: this workaround is not necessary if UMLResourcesUtil.init( resourceSet) is registered in the generator launcher, in which case all primitive type proxies resolve correctly and name is always accessible. The workaround degrades gracefully when registration is present. --- AQL operations used: aType.eClass().name - AQL operation on EObject: returns the EMF metaclass name. Returns 'PrimitiveType' for all uml::PrimitiveType instances, including unresolved proxies. aType.toString() - Returns the Java toString() representation of the type. For unresolved proxies this contains the proxy URI including the type name fragment after '#', e.g.: '...PrimitiveTypeImpl@x (eProxyURI: ...#Boolean)'. s.lastIndex('#') - Returns the index of the last occurrence of '#' in the string. s.substring(n) - Returns the substring from position n onwards. .replace('\\)','') - Removes the trailing ')' from the extracted fragment using a regex escape. aType.name - EStructuralFeature on uml::NamedElement: returns the name of a resolved type directly.
public Boolean u_isNotPrimitiveType(aType) Returns true if the specified type is not a UML primitive type, i.e. it is a Class, DataType, Interface, or other non-primitive classifier.
