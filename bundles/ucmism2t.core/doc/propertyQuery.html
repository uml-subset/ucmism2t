module ucmism2t::queries::propertyQuery

Module contains queries with a UML property as receiver. This includes queries for retrieving property metadata (multiplicity, cardinality), classifying properties as attributes or association ends, and navigating to the owning classifier or association. Note: In UML, association ends are represented as properties. Queries in this module handle both plain attributes (association = null) and association ends (association <> null). The distinction is made explicit in the query documentation where relevant. Note: Queries that find properties starting from a class or data type are in classQuery and dataTypeQuery respectively, since their receiver is the owning classifier rather than the property itself. Related modules: - classQuery: queries with a UML class as receiver, including queries that find attributes and association ends of a class - dataTypeQuery: queries with a UML data type as receiver, including queries that find attributes of a data type - associationQuery: queries with a UML association as receiver, since association ends are properties
Metamodels http://www.eclipse.org/uml2/5.0.0/UML, http://www.eclipse.org/uml2/5.0.0/Types, http://www.eclipse.org/uml2/5.0.0/UML/Profile/Standard
