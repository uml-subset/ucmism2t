module ucmism2t::queries::classQuery

Module contains queries with a UML class as receiver. This includes queries for navigating the class hierarchy (superclasses, subclasses), finding associations, inherited attributes, and class classification. Note: Queries applicable to both classes and data types are in classifierQuery, since both are subtypes of Classifier. Related modules: - dataTypeQuery: queries with a UML data type as receiver - classifierQuery: queries with a UML classifier as receiver, applicable to both classes and data types - associationQuery: queries with a UML association as receiver - propertyQuery: queries with a UML property as receiver
Metamodels http://www.eclipse.org/uml2/5.0.0/UML, http://www.eclipse.org/uml2/5.0.0/Types, http://www.eclipse.org/uml2/5.0.0/UML/Profile/Standard

        a.u_ownedEndClass() <> aClass
        and a.u_otherEndClass() <> aClass)
      ->select(a |
        aClass.u_allSuperClasses()->excludes(a.u_ownedEndClass())
        or aClass.u_allSuperClasses()->excludes(a.u_otherEndClass()))
      ->sortedBy(a | a.name)
  in
    if associations->size() > 3 then
      associations->subOrderedSet(1, 3)
    else
      associations
    endif
/]
