module ucmism2t::queries::dataTypeQuery

Module contains queries with a UML data type as receiver. This includes queries for navigating the data type hierarchy (supertypes, subtypes), finding properties that use a data type, and data type classification. Note: Queries applicable to both classes and data types are in classifierQuery, since both are subtypes of Classifier. Related modules: - classQuery: queries with a UML class as receiver - classifierQuery: queries with a UML classifier as receiver, applicable to both classes and data types
Metamodels http://www.eclipse.org/uml2/5.0.0/UML, http://www.eclipse.org/uml2/5.0.0/Types, http://www.eclipse.org/uml2/5.0.0/UML/Profile/Standard

[query public u_subDataTypes(aDataType : uml::DataType) : OrderedSet(uml::DataType) =
  aDataType.eInverse(uml::Generalization)
	  ->select(g1 | g1.general = aDataType)
	  ->collect(g2 | g2.specific)
	  ->filter(uml::DataType)
	  ->sortedBy(c | c.name)

query public u_contextClassesOrDataTypes

[query public u_contextClassesOrDataTypes(aDataType : uml::DataType) : OrderedSet(uml::Classifier) = ...]
Returns an ordered set of classifiers related to the specified data type as context classifiers for diagram generation: - classifiers that own properties using the data type - all super data types - classifiers that own properties using any super data type (limited to 3 per super type) - all sub data types - abstraction clients of the data type - abstraction suppliers of the data type The data type itself is excluded from the result. Note: p.owner is typed as uml::Element and requires an explicit oclAsType(uml::Classifier) cast. Sub- and super data types as well as abstraction helpers returning OrderedSet(uml::DataType) do not need a cast since DataType is a subtype of Classifier and AQL widens the union automatically.

aDataType : uml::DataType
- A UML data type.

[query public u_contextClassesOrDataTypes(
  aDataType : uml::DataType) : OrderedSet(uml::Classifier) =
  let useClassifiers : OrderedSet(uml::Classifier) =
    aDataType.u_dataTypeUseProperties()
    ->collect(p | p.owner.oclAsType(uml::Classifier))
  in
  let superTypes : OrderedSet(uml::DataType) =
    aDataType.u_allSuperDataTypes()
  in
  useClassifiers
    ->union(superTypes)
    ->union(
        superTypes
        ->collect(s | s.u_limitedDataTypeUseProperties())
        ->collect(p | p.owner.oclAsType(uml::Classifier)))
    ->union(aDataType.u_allSubDataTypes())
    ->union(aDataType.u_abstractionClientsDataType())
    ->union(aDataType.u_abstractionSuppliersDataType())
    ->excluding(aDataType)
    ->asOrderedSet()
    ->sortedBy(c | c.name)
/]
