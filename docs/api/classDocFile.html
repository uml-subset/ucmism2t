template public processClassDoc

[template public processClassDoc(aClass : uml::Class, folderType : String, aProfilePackage : uml::Package)]
Processes a class and writes all output files for it. When aProfilePackage is null (universe context): - Uses u_filePath for file paths - Emits the canonical RST anchor .. _<qualifiedName>: - No attribute filtering (all attributes included) - Association table shows all associations - Diagram uses pu_classDiagram(null) When aProfilePackage is not null (profile context): - Uses u_profileFilePath for file paths - Emits the profile-specific anchor .. _<profileName>-<qualifiedName>: - Adds a "See also" reference to the universe file - Attributes filtered by u_isAttributeInProfile - Superclasses in attribute/association tables filtered to those in the profile subset - Association table shows only associations where both ends are in the profile subset - Diagram uses pu_classDiagram(aProfilePackage)

Parameters

aClass : uml::Class
- The UML class to process.
folderType : String
- 'universe' to emit the canonical anchor, any other value to suppress it.
aProfilePackage : uml::Package
- The profile sub-package context, or null for universe generation.
