module ucmism2t::queries::modelQuery

Module contains queries with a UML model as receiver. This includes queries for retrieving model metadata (acronym, title, version, URI, language), navigating the model structure (main package, all classes, all data types, all packages), and property file access. Note: The main package is the top-level package of the model as specified by the property MAIN_PACKAGE_NAME. All generation targets operate on the main package rather than the model root directly. Note: Model metadata is resolved in order of priority: (1) property file value, (2) ModelIdentification data type in the model, (3) built-in fallback value. This allows property file values to override model metadata without modifying the model. Related modules: - packageQuery: queries with a UML package as receiver, since Model is a subtype of Package in UML - classQuery: queries with a UML class as receiver - dataTypeQuery: queries with a UML data type as receiver
Metamodels http://www.eclipse.org/uml2/5.0.0/UML, http://www.eclipse.org/uml2/5.0.0/Types, http://www.eclipse.org/uml2/5.0.0/UML/Profile/Standard

u_mainPackage(aModel) : uml::Package Returns the main package for generation, determined by the 'MAIN_PACKAGE_NAME' property. Property matching: The property value is matched against the qualified name of each package (uml::Package.qualifiedName), which includes the full path, e.g. 'MyModel::Domain::Core'. A simple unqualified name such as 'Core' will NOT match. If the property holds a simple name, use p.name instead. Fallback to model: The model itself is returned as a uml::Package when: - 'MAIN_PACKAGE_NAME' is not set (empty string), - the property equals the model name, or - no package with the given qualified name is found. The second condition means that explicitly naming the model is treated the same as leaving the property unset. Non-determinism: If multiple packages share the same qualified name across different subtrees, ->first() returns the first match in containment order. The model is assumed to contain unique qualified names, which is the standard UML constraint. Type note: uml::Model is a specialisation of uml::Package, so returning aModel as uml::Package requires no cast.

[query public u_mainPackage(aModel : uml::Model) : uml::Package =
  let propertyValue : String =
    'MAIN_PACKAGE_NAME'.getPropertyValue()
  in
  let matchedPackages : Sequence(uml::Package) =
    aModel.eAllContents(uml::Package)
      ->select(p | p.qualifiedName = propertyValue)
  in
  if propertyValue = ''
    or propertyValue = aModel.name
    or matchedPackages->isEmpty()
  then
    aModel
  else
    matchedPackages->first()
  endif
/]

[query public u_subsetPackages(
  aModel : uml::Model) : OrderedSet(String) =
  let mainPkg : uml::Package = aModel.u_mainPackage() in
  mainPkg.eAllContents(uml::Classifier)
    ->collect(c | c.qualifiedName)
    ->select(s | aModel.u_subsetItems()->includes(
        s.substring(s.lastIndex('::') + 2)))
    ->collect(s | s.substring(1, s.lastIndex('::') - 1))
    ->collect(s | s.tokenize('::'))
    ->asOrderedSet()
/]
