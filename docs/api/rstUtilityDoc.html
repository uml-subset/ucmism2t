module ucmism2t::templates::target::doc::rstUtilityDoc

Module contains utility templates for generating reStructuredText (RST) documentation and PlantUML context diagrams from UML models. PlantUML diagram templates: pu_classDiagram - Context diagram for a UML class, showing associated classes, super/sub classes, associations, and abstraction relationships. pu_dataTypeDiagram - Context diagram for a UML data type, showing classes and data types that use the type, the dotted usage connection, and the inheritance hierarchy. pu_superClass - Helper: renders superclass nodes and their limited inherited associations for pu_classDiagram. pu_subClasses - Helper: renders subclass inheritance arrows recursively for pu_classDiagram. pu_superDataType - Helper: renders supertype inheritance for pu_dataTypeDiagram. pu_subDataTypes - Helper: renders subtype inheritance for pu_dataTypeDiagram. RST documentation templates: rst_mainIndexHead - Index page header and toctree. rst_generationMessageDoc - Generation message comment. rst_header - Section header underline. rst_classOrDataTypeInheritance - Collapsible inheritance tree. rst_subClasses - Recursive subclass list. rst_processAttributeInTable - Table row for a class attribute. rst_processAssociationInTable - Table row for an association. rst_refDataType - RST :ref: link for a type. rst_simpleQualifiedClassNameReference - :ref: for a class. rst_simpleQualifiedClassifierNameReference - :ref: for a classifier. rst_classNameReference - :ref: for a class by qualified name. rst_classifierNameReference - :ref: for a classifier by qualified name. rst_className - Class name with italic for abstract. rst_addClassReferencesToDocumentation - Injects :ref: links into documentation strings. abstractionType - UML abstraction stereotype label. HTML diagram modal templates: diagramModalPreCode - Opening tags for the SVG diagram modal. diagramModalPostCode - Closing tags and modal controls. Indentation utilities: e_indent - Post-processor: prefixes every non-empty line with a fixed number of spaces (used for RST include blocks). e_indent2 - Post-processor: inserts indentation after each newline.
Metamodels http://www.eclipse.org/uml2/5.0.0/Types, http://www.eclipse.org/uml2/5.0.0/UML, http://www.eclipse.org/uml2/5.0.0/UML/Profile/Standard

abstractionType(anAbstraction) Returns the PlantUML stereotype label for a UML abstraction, derived from the abstraction's name: contains 'derivesFrom' -> <<Derive>> contains 'refines' -> <<Refine>> contains 'tracesTo' -> <<Trace>>
pu_superClass(aClass, mainClass, aSubsetPackage) Renders the superclass hierarchy for the focal class in a context diagram. For each direct superclass (subject to subset filtering): 1. Emits a note if the superclass has more than maxInherited associations, stating how many are shown. 2. Iterates up to maxInherited inherited associations of the superclass (via u_limitedAssociations), rendering each as a PlantUML association arrow using u_isAssociationInSubset for subset filtering and u_commentBody for the tooltip. 3. Renders the superclass node with its attributes. 4. Emits the generalization arrow. 5. Recurses upward via pu_superClass. The maximum number of inherited associations shown per superclass is controlled by the let binding 'maxInherited'. This local cap prevents diagrams from becoming unreadable when a superclass has many associations.
pu_superDataType(aDataType) Renders supertype inheritance for a data type context diagram. For each direct supertype, emits usage connections (dotted lines) for the supertype's limited-use properties, the inheritance arrow, and recurses upward.
pu_subClasses(aClass, aSubsetPackage) Renders subclass inheritance arrows recursively for a class context diagram. Each subclass is subject to subset filtering via u_profileSubsetClasses when 'profiles' is true. Recurses into each subclass's own subclasses.
pu_subDataTypes(aDataType) Renders subtype inheritance arrows recursively for a data type context diagram. Recurses into each subtype's own subtypes.
rst_processAttributeInTable(anAttribute, aClassifier) Generates a table row in RST list-table format for a single class or data type attribute. The row is subject to subset filtering. Columns: attribute name, owning classifier reference, description, type reference, multiplicity, and default value.
rst_refDataType(aType) Generates a RST :ref: link for a UML type. UML primitive types (Boolean, Integer, Real, String) are rendered as plain text; all other types are rendered as a :ref: cross-reference.
rst_processAssociationInTable(a, indent) Generates a table row in RST list-table format for a single UML association. Columns: target multiplicity, association predicate (short name), source class reference with qualified name, source multiplicity.
rst_simpleQualifiedClassNameReference(aClass) Generates a RST :ref: cross-reference for a class, using the simple qualified classifier name as the visible label and the fully qualified name as the reference target.
rst_simpleQualifiedClassifierNameReference(aClassifier) Generates a RST :ref: cross-reference for a classifier, using the simple qualified classifier name as the visible label and the fully qualified name as the reference target.
rst_classNameReference(aClass) Generates a RST :ref: cross-reference for a class using only the fully qualified name (no visible label override).
rst_classifierNameReference(aClassifier) Generates a RST :ref: cross-reference for a classifier using only the fully qualified name (no visible label override).
rst_className(aClass) Renders a class name in RST, wrapping it in italic emphasis markers when the class is abstract.
e_indent(s, indentAmount) Post-processing template that prefixes every non-empty line of a multi-line string with a fixed number of spaces. Used to produce RST-indented include blocks when a generated diagram is embedded in an RST file.
e_indent2(s, indent) Post-processing template that inserts a fixed indentation string after every newline character in a string. Complementary to e_indent for use within a string value rather than on block boundaries.
rst_classOrDataTypeInheritance(aClassifier) Generates the RST inheritance tree section for a classifier, rendered as a collapsible dropdown. The tree shows all superclass ancestors from the root downward to the focal class, followed by all direct and indirect subclasses. When the classifier has superclasses, the root ancestor appears first without indentation and each subsequent ancestor is indented by 4 em-spaces per level, with the focal class shown in :focus:. When the classifier has no superclasses but does have subclasses, only the focal class and its subtree are shown.
rst_subClasses(aClassifier, indent) Generates a recursive RST subclass/subtype list for the inheritance tree dropdown. Each entry is rendered with appropriate CSS class (abstract or regular) and indented by the given indent string. Recurses into each child's own subtree. When 'profiles' is true, only subclasses/subtypes that are members of the dependency-defined profile subset are shown (checked by object identity via u_profileSubsetClasses for classes and u_profileSubsetDataTypes for data types). When 'includeAllItems' is true, all subclasses and subtypes are shown regardless of the subset.
diagramModalPreCode(anOclAny) Generates the opening HTML markup for the SVG diagram modal container. The modal allows the diagram to be enlarged and pan/zoomed in the browser. Must be paired with diagramModalPostCode.
diagramModalPostCode(anOclAny) Generates the closing HTML markup for the SVG diagram modal, including the modal overlay, pan/zoom controls, and download buttons for PNG and SVG export.

[template public pu_classDiagram(aClass : uml::Class, aSubsetPackage : uml::Package)]
  @startuml
  [aClass.pu_generationMessageDoc()/]
  !pragma ratio 0.5625
  [aClass.pu_options()/]
  
  title UML Diagram: Class [aClass.name/] in Context\n
  [let url : String = '../' + aClass.u_path() + '.html']
    [let label : String =
        aClass.u_model().u_modelTitle()
        + ' (' + aClass.u_model().u_modelAcronym() + ') '
        + aClass.u_model().u_modelMajorVersion()
        + '.' + aClass.u_model().u_modelMinorVersion()
        + ' - ' + aClass.u_simpleQualifiedClassifierName()]
      <style>
      title { FontSize: 20 }
      footer { hyperlinkUnderlineThickness 0 }
      </style>
      footer \n\n[url.pu_linkWithLabel(label)/]
      
    [/let]
  [/let]
  
  [if (aClass.u_allSuperClasses()->notEmpty() or aClass.u_allSubClasses()->notEmpty())]
    legend top left
    **Hint**
    <color:grey>- The arrows of the inheritance tree are <color:['uml-diagram-inheritance-arrow-color'.getPropertyValue()/]>colored<color:grey>.
    endlegend
  [/if]
  
  ' Core class of diagram
  [if (aClass.isAbstract)]abstract [/if]class [aClass.pu_classifierNameWithLabel('black', '<size:10>' + aClass.package.name + ':\\n')/] ['uml-diagram-class-emphasis-color'.getPropertyValue()/] {
  [for (anAttribute : uml::Property | aClass.ownedAttribute->select(temp1 | temp1.association = null)
    ->select(a | (aSubsetPackage <> null and a.u_isAttributeInProfile(aClass, aSubsetPackage)) or (aSubsetPackage = null and (aClass.name.u_subsetClassAttributes()->includes(a.name) or 'includeAllItems'.isPropertyTrue())))
    ->sortedBy(a | a.name))]
      [anAttribute.name/] : [anAttribute.type.pu_typeWithLink()/]
  [/for]
  }
  
  ' Associated classes without superclass.
  ' Placed in a 'together' block to reduce Graphviz layout constraints.
  [let directAssocClasses : OrderedSet(uml::Class) =
      aClass.u_associatedClasses() - aClass.superClass
        ->sortedBy(temp2 | temp2.package.name)
        ->sortedBy(temp3 | temp3.name)]
    [if (directAssocClasses->select(c | (aSubsetPackage <> null and aSubsetPackage.u_childDependencySupplierClasses()->includes(c)) or (aSubsetPackage = null and 'includeAllItems'.isPropertyTrue()))->notEmpty())]
      together {
      [for (contextClass : uml::Class | directAssocClasses)]
        [let inSubset1 : Boolean = (aSubsetPackage <> null and aSubsetPackage.u_childDependencySupplierClasses()->includes(contextClass)) or (aSubsetPackage = null and 'includeAllItems'.isPropertyTrue())]
          [if (inSubset1)][if (contextClass.isAbstract)]abstract [/if]class [contextClass.pu_elementWithLink('blue', '<size:10>' + contextClass.package.name + ':\\n')/][/if]
        [/let]
      [/for]
      }
    [/if]
  [/let]
  
  ' Abstraction supplier classes.
  [let abstractionSuppliers : OrderedSet(uml::Class) =
      aClass.eInverse(uml::Abstraction)->asSequence()
        ->collect(temp4 | temp4.supplier)
        ->collect(temp5 | temp5.oclAsType(uml::Class))
        ->sortedBy(temp6 | temp6.package.name)
        ->sortedBy(temp7 | temp7.name)
        ->select(c | 'includeAllItems'.isPropertyTrue())
        ->asOrderedSet()]
    [if (abstractionSuppliers->notEmpty())]
      together {
      [for (contextClass : uml::Class | abstractionSuppliers)]
        [if (contextClass.isAbstract)]abstract [/if]class [contextClass.pu_elementWithLink('blue', '<size:10>' + contextClass.package.name + ':\\n')/]
      [/for]
      }
    [/if]
  [/let]
  
  ' Remaining context classes (excluding direct associated and abstraction suppliers).
  [for (contextClass : uml::Class |
      aClass.u_contextClasses()
        - aClass.eInverse(uml::Abstraction)->asSequence()
            ->collect(temp8 | temp8.supplier)
            ->collect(temp9 | temp9.oclAsType(uml::Class))
            ->asOrderedSet()
        - (aClass.u_associatedClasses() - aClass.superClass)
            ->sortedBy(temp10 | temp10.package.name)
            ->sortedBy(temp11 | temp11.name))]
    [let inSubset2 : Boolean = (aSubsetPackage <> null and aSubsetPackage.u_childDependencySupplierClasses()->includes(contextClass)) or (aSubsetPackage = null and 'includeAllItems'.isPropertyTrue())]
      [if (inSubset2)][if (contextClass.isAbstract)]abstract [/if]class [contextClass.pu_elementWithLink('blue', '<size:10>' + contextClass.package.name + ':\\n')/][/if]
    [/let]
  [/for]
  
  ' Associations of the focal class.
  [for (anAssociation : uml::Association | aClass.u_associations())]
    [if (anAssociation.u_isAssociationInSubset(aClass, aSubsetPackage))]
      [if (aClass <> anAssociation.ownedEnd->first().type)]
        [let srcClass : uml::Classifier = anAssociation.ownedEnd->first().type.oclAsType(uml::Classifier)]
          [let aggKind : String = anAssociation.ownedEnd->first().aggregation.pu_aggregationKind()]
            [let tooltip : String = ' <U+2022> ' + anAssociation.u_shortAssociationName() + ':\\n' + anAssociation.u_commentBody()]
              [aClass.qualifiedName/] <-['['/]#grey]-[aggKind/] [srcClass.qualifiedName/] ['#'.pu_link(tooltip)/] : [anAssociation.u_shortAssociationName()/]
            [/let]
          [/let]
        [/let]
      [else]
        [let tgtClass : uml::Classifier = anAssociation.ownedEnd->first().getOtherEnd().type.oclAsType(uml::Classifier)]
          [let aggKind : String = anAssociation.ownedEnd->first().getOtherEnd().aggregation.pu_aggregationKind()]
            [let tooltip : String = ' <U+2022> ' + anAssociation.u_shortAssociationName() + ':\\n' + anAssociation.u_commentBody()]
              [aClass.qualifiedName/] [aggKind/]-['['/]#grey]-> [tgtClass.qualifiedName/] ['#'.pu_link(tooltip)/] : [anAssociation.u_shortAssociationName()/]
            [/let]
          [/let]
        [/let]
      [/if]
    [/if]
  [/for]
  
  [if (aClass.superClass->notEmpty())]
    ' Superclass hierarchy
    [aClass.pu_superClass(aClass, aSubsetPackage)/]
  [/if]
  [if (aClass.u_subClasses()->notEmpty())]
    ' Subclass hierarchy
    [aClass.pu_subClasses(aSubsetPackage)/]
  [/if]
  
  ' Abstraction relationships
  [if ('includeAllItems'.isPropertyTrue() and aClass.u_model().u_allAbstractionClients()->includes(aClass))]
    [for (anAbstraction : uml::Abstraction | aClass.eInverse(uml::Abstraction))]
        [aClass.qualifiedName/] .....> [anAbstraction.supplier->asSequence()->collect(temp16 | temp16.oclAsType(uml::Classifier))->collect(temp17 | temp17.qualifiedName)/] : [anAbstraction.abstractionType()/] 
    [/for]
  [/if]
  [if (aClass.u_model().u_allAbstractionSuppliers()->includes(aClass))]
    [for (anAbstraction : uml::Abstraction | aClass.eInverse(uml::Abstraction))]
        [aClass.qualifiedName/] <..... [anAbstraction.client->asSequence()->collect(temp18 | temp18.oclAsType(uml::Classifier))->collect(temp19 | temp19.qualifiedName)/] : [anAbstraction.abstractionType()/] 
    [/for]
  [/if]
  @enduml[/template]

      </style>

    [/let]
  [/let]
  
  
  legend top right
  **Hint(s)**
  <color:grey>- The use of the data type is represented here by a dotted line (not formal UML).
  [if (aDataType.u_allSuperDataTypes()->notEmpty() or aDataType.u_allSubDataTypes()->notEmpty())]
    <color:grey>- The arrows of the inheritance tree are <color:['uml-diagram-inheritance-arrow-color'.getPropertyValue()/]>colored<color:grey>.
  [/if]
  endlegend
  
  ' Core data type of diagram
  [if (aDataType.isAbstract)]abstract [/if]class [aDataType.pu_classifierNameWithLabel('black', '<size:10> \\n')/] \

  [for (anAttribute : uml::Property | aDataType.ownedAttribute->select(temp20 | temp20.association = null))]
    [if ('includeAllItems'.isPropertyTrue() or aDataType.name.u_subsetDataTypeAttributes()->includes(anAttribute.name))]
        [anAttribute.name/] : [anAttribute.type.pu_typeWithLink()/]
    [/if]
  [/for]
  }
  
  ' Data type definitions in own package
  [for (contextClassifier : uml::Classifier | aDataType.u_contextClassesOrDataTypes()->select(temp22 | temp22.package = aDataType.package))]
    [if (contextClassifier.isAbstract)]abstract [/if]class [contextClassifier.pu_elementWithLink('blue', '<size:10> \\n')/] {
    [for (anAttribute : uml::Property | contextClassifier.attribute->select(temp21 | temp21.association = null))]
      [if ('includeAllItems'.isPropertyTrue() or contextClassifier.name.u_subsetDataTypeAttributes()->includes(anAttribute.name))]
          [anAttribute.name/] : [if (aDataType = anAttribute.type)][anAttribute.type.name/][else][anAttribute.type.pu_typeWithLink()/][/if]
      [/if]
    [/for]
    }
  [/for]
  
  ' Data type definitions in other packages
  [for (aPackage : uml::Package | aDataType.u_contextPackages())]
    [for (contextClassifier : uml::Classifier | aDataType.u_contextClassesOrDataTypes()->select(temp24 | temp24.package = aPackage))]
        [if (contextClassifier.isAbstract)]abstract [/if]class [contextClassifier.pu_elementWithLink('blue', '<size:10><color:grey>' + contextClassifier.package.name + ':\\n')/] {
      [for (anAttribute : uml::Property | contextClassifier.attribute->select(temp23 | temp23.association = null))]
        [if ('includeAllItems'.isPropertyTrue() or contextClassifier.name.u_subsetDataTypeAttributes()->includes(anAttribute.name))]
            [anAttribute.name/] : [if (aDataType = anAttribute.type)][anAttribute.type.name/][else][anAttribute.type.pu_typeWithLink()/][/if]
        [/if]
      [/for]
      }
    [/for]
  [/for]

        [anAttribute.owner.oclAsType(uml::Classifier).qualifiedName/]::[anAttribute.name/] ---- [aDataType.qualifiedName/] #grey;line.dotted;
    [/if]
  [/for]
  }
  
  [if (aDataType.general->notEmpty())]
    ' Supertype hierarchy
    [aDataType.pu_superDataType()/]
  [/if]
  [if (aDataType.u_subDataTypes()->notEmpty())]
    ' Subtype hierarchy
    [aDataType.pu_subDataTypes()/]
  [/if]
  
  ' Abstraction relationships
