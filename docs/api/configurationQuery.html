module ucmism2t::queries::configurationQuery

Module contains queries that retrieve configuration values from the generator properties file. Property keys are constructed dynamically using the 'subset.name' property as a prefix.
Metamodels http://www.eclipse.org/uml2/5.0.0/UML
Sourceucmism2t/queries/configurationQuery.mtl

Query Summary

NameDescription
u_subsetPrefix(anEObject) : String Returns the subset name prefix used to build property keys. Returns an error marker string if 'subset.name' is not defined, ensuring misconfiguration is visible in generated output.
u_subsetTitle(anEObject) : String Returns the title of the subset.
u_subsetClasses(anEObject) : Sequence(String) Returns a sequence of names of the subset classes. Returns an empty sequence if the property is not defined.
u_subsetGeneralizedClasses(anEObject) : Sequence(String) Returns a sequence of names of the generalized subset classes. Returns an empty sequence if the property is not defined.
u_subsetAllClasses(anEObject) : Sequence(String) Returns a sequence of names of all subset classes (subset classes and generalized subset classes).
u_subsetDataTypes(anEObject) : Sequence(String) Returns a sequence of names of the subset data types. Returns an empty sequence if the property is not defined.
u_subsetEnumerations(anEObject) : Sequence(String) Returns a sequence of names of the subset enumerations. Returns an empty sequence if the property is not defined.
u_subsetItems(anEObject) : Sequence(String) Returns a sequence of names of all subset items (classes, data types, and enumerations).
u_subsetClassAttributes(aClassName) : Sequence(String) Returns a sequence of attribute names for a specific subset class. Returns an empty sequence if the property is not defined.
u_subsetDataTypeAttributes(aDataTypeName) : Sequence(String) Returns a sequence of attribute names for a specific subset data type. Returns an empty sequence if the property is not defined.

[query public u_subsetClasses(anEObject : ecore::EObject) : Sequence(String) =
  let raw : String =
    (anEObject.u_subsetPrefix() + '.class')
    .getPropertyValue()
    .replaceAll('\\s', '')
  in
  if raw = '' then Sequence{}
  else raw.tokenize(',')
  endif
