module ucmism2t::queries::associationQuery

Module contains queries with a UML association as receiver. This includes queries for navigating association ends (owned end, other end, source class, target class) and filtering associations for diagram generation purposes. Note: Queries that find associations starting from a class are in classQuery, since their receiver is a UML class. Related modules: - classQuery: queries with a UML class as receiver, including queries that find associations of a class - propertyQuery: queries with a UML property as receiver, since association ends are properties in UML
Metamodels http://www.eclipse.org/uml2/5.0.0/UML, http://www.eclipse.org/uml2/5.0.0/Types, http://www.eclipse.org/uml2/5.0.0/UML/Profile/Standard

u_ownedEnd(anAssociation) : uml::Property Returns the source (subject) end of a binary directed association. A binary directed association can be understood as a triple: subject -- predicate (association name) --> object The source end is the subject end — owned by the association itself (ownedEnd) — as opposed to the target (object) end, which is owned by the source class via ownedAttribute. Note: Intended for use with binary directed associations only. See: u_otherEnd(uml::Association) - Returns the target (object) end.

A binary directed association can be understood as a triple: subject -- predicate (association name) --> object The target end is the object end — owned by the source class via ownedAttribute (memberEnd minus ownedEnd) — as opposed to the source (subject) end, which is owned by the association itself. Note: Intended for use with binary directed associations only. See: u_ownedEnd(uml::Association) - Returns the source (subject) end.

[query public u_shortAssociationName(
  anAssociation : uml::Association) : String =
  let n : String = anAssociation.name in
  if n = ''
  then 'WARNING: no association name!'
  else
    if n.contains('_')
    then
      let nameAfterFirst : String =
        n.substring(n.index('_') + 1)
      in
      if nameAfterFirst.contains('_')
      then nameAfterFirst.substring(1, nameAfterFirst.index('_') - 1)
      else 'WARNING: association name has only one underscore!' + n
      endif
    else n
    endif
  endif
/]
