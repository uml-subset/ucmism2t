module ucmism2t::queries::associationQuery

Module contains queries with a UML association as receiver. This includes queries for navigating association ends (owned end, other end, source class, target class) and filtering associations for diagram generation purposes. Note: Queries that find associations starting from a class are in classQuery, since their receiver is a UML class. Related modules: - classQuery: queries with a UML class as receiver, including queries that find associations of a class - propertyQuery: queries with a UML property as receiver, since association ends are properties in UML
Metamodels http://www.eclipse.org/uml2/5.0.0/UML, http://www.eclipse.org/uml2/5.0.0/Types, http://www.eclipse.org/uml2/5.0.0/UML/Profile/Standard

[query public u_shortAssociationName(
  anAssociation : uml::Association) : String =
  if anAssociation.name.contains('_') then
    let nameAfterFirst : String =
      anAssociation.name.substring(anAssociation.name.index('_') + 1)
    in
    nameAfterFirst.substring(1, nameAfterFirst.index('_') - 1)
  else
    anAssociation.name
  endif
/]
